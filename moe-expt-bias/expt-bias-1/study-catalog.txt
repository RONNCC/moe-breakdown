================================================================================
EXPT-BIAS-1: Is Bias in MoE Concentrated and More Localizable than in Dense LLMs?
Last updated: 2026-07-06
================================================================================

OVERVIEW
--------
Post-hoc bias-attribution study via expert-level Shapley values. Implements
the study design in ../study_design_C1_C4.md (claims C1 + C4, extensions
C2/C3). Computes a bias-Shapley vector phi over MoE experts (or, for dense
models, transformer FFN layers via leave-one-out approximation), then derives
concentration/localizability metrics (normalized entropy H, Gini, top-k mass
fraction) from phi.

Package: src/moe_bias_shapley/
  config.py      — BiasStudyConfig + SlurmConfig, YAML loading
  benchmarks.py  — StereoSet / BBQ loaders -> PromptPair (stereo vs anti-stereo)
  hooks.py       — generic MoE router-hook + dense FFN-layer discovery
  shapley.py     — routing_contrast (fast/approx), exact ablation Shapley
                   (2^K over active experts), dense_loo (leave-one-out)
  metrics.py     — normalized entropy, Gini, top-fraction, localizability ratio
  reporting.py   — JSON + .npy result serialization

Driver: scripts/run_bias_study.py (single study run)
Submit: scripts/submit_slurm_study.py --config configs/<study>.yaml
Env:    scripts/bootstrap_uv_env.sh (uv venv + torch/transformers/datasets)
Sbatch: slurm/run_bias_study.sbatch

NOTE ON CLUSTER: see ../../moe-routing/RUNNING-ICE.md — ICE nodes are
temperamental (NVSHMEM/IB quirks, node exclusions). This study only needs
single-GPU, single-node jobs (no DeepEP/NVSHMEM), so it avoids most of those
pitfalls, but still follow the module/venv/cache conventions there
(scratch repo path, $TMPDIR caches, uv envs on /storage or $TMPDIR).

STUDY INDEX
================================================================================

Experiment 1 — Concentration vs sparsity ladder (RQ1 / C1)
  configs/study.olmoe.concentration.yaml             OLMoE-1B-7B      (sparsest, top-1)
  configs/study.phi3.5-moe.concentration.yaml         Phi-3.5-MoE      (mid-sparsity, top-2/16)
  configs/study.mixtral-8x7b.concentration.yaml       Mixtral-8x7B     (densest MoE in ladder, top-2/8)
  Expected (H1): entropy H monotonically decreases (concentration increases)
  as N_A/N decreases across this ladder. Chinese-origin models excluded
  per GT ICE institutional policy (see ../study_design_C1_C4.md Sec 2.1).

Experiment 2 — MoE vs dense localizability (RQ2 / C4)
  configs/study.olmo-7b.dense-baseline.yaml           OLMo-7B (dense)  — primary matched
                                                       pair vs OLMoE-1B-7B (same family/data)
  configs/study.phi3.5-mini-dense.dense-baseline.yaml Phi-3.5-mini (dense) — secondary matched
                                                       pair vs Phi-3.5-MoE
  configs/study.llama-3.1-8b.dense-crosscheck.yaml    Llama-3.1-8B (dense) — tertiary cross-check
  configs/study.llama-2-7b.dense-crosscheck-2.yaml    Llama-2-7B (dense)   — cross-generation
                                                       complement; same scale/depth as 3.1-8B,
                                                       different training generation (Llama 2 vs 3.1)
  Expected (H2): H_MoE < H_dense (localizability ratio LR > 1).
  Dense attribution uses leave-one-out (LOO) layer ablation — an approximation,
  not exact Shapley (see shapley.py::compute_dense_layer_contrast docstring).

Experiment 3 — Collectivity check (C2-lite)
  Not yet a standalone config. Reuses Experiment 1 configs with
  shapley_method: exact on a small ablation_layer_indices subset to get
  Shapley interaction values (marginal vs synergy). Run manually via
  shapley.compute_shapley_interactions_for_pair (returns per-pair
  InteractionResult: marginal phi + pairwise interaction values + synergy
  fraction) on a prompt subsample, then shapley.aggregate_interaction_results
  to summarize across the subsample, before scaling up.

Experiment 4 — Independent cross-check (robustness)
  Validates Shapley rankings against expert-ablation disparity drop. Use
  shapley_method: exact on the top-phi experts flagged by Experiment 1/2 runs;
  compare the ablation curve against the Shapley ranking. No standalone
  config yet — depends on Experiment 1/2 output (top_players in result.json).

Experiment 5 — Demographic specificity (RQ3 / C3)
  configs/study.olmoe.demographic.yaml               OLMoE-1B-7B, per-cohort phi split
  Produces per_group_phi (result.json: per_group_concentration_metrics) keyed
  by StereoSet `target` (demographic group). Downstream: compute
  Jensen-Shannon divergence across cohorts' phi distributions.

Experiment 6 — Ladder-wide causal ablation (extends Exp4 to full ladder)
  Reuses existing Exp1 configs; submit via submit_slurm_experiment4.py.
  Includes random + high-routing controls (auto-generated in run_experiment4_ablation.py).
  Results land in <result_dir>/experiment4/experiment4_ablation_curve.json
  Models: OLMoE (n=100), Mixtral (n=60), Phi-3.5-MoE (n=60), OLMo-7B dense (n=60)
  Key question: does phi-ranked ablation drop faster than random/high-routing controls?

Experiment 7 — Proxy-vs-causal agreement test
  scripts/run_experiment7_proxy_agreement.py --config configs/study.mixtral-8x7b.concentration.yaml
  Reuses run_experiment_script.sbatch via submit_slurm_experiment4.py with SCRIPT override.
  Computes Spearman ρ between routing_contrast ranking and exact Shapley ranking on Mixtral
  (K=2/8, 2^8=256 coalitions → tractable). 20 pairs, first + last MoE layer.
  Results: <result_dir>/experiment7/experiment7_proxy_agreement.json

Experiment 8 — Same-mechanism comparison (method-confound resolution)
  configs/study.olmoe.lloo.yaml          OLMoE with shapley_method: dense_loo
  configs/study.phi3.5-moe.lloo.yaml     Phi-3.5-MoE with shapley_method: dense_loo
  Runs layer-level LOO on MoE models for apples-to-apples H vs dense baselines.
  Key question: does H_lloo(MoE) stay high (≈0.90) or drop toward H_dense (0.63–0.76)?
